OGC Web Services

A legacy suite of specifications, superseded by the modern OGC APIs.

OGC Web Services were created more than ten years ago, when the web technologies looked very different from what is used nowadays. OGC encourages the transition from OWS, and"Technical Committee Policies and Procedures 05-020r29" presents a process for deprecating API elements in OGC Standards. If you are going to implement a standard from scratch, please consider using one of the OGC APIs instead.

Who is behind the OGC Standards?

OGC Standards are developed through a member-driven consensus process, which creates royalty free, publicly available, open geospatial standards. The Open Geospatial Consortium (OGC) is the organisation which drives this process. It is supported by an active community of members, with involvement from a large range of organizations, as well as smaller ones.
